# 🏠 Housing in Mexico — Data Analysis Project

This project explores real estate data across different regions in Mexico to understand how housing prices vary by area, state, and other factors. It was developed as part of my data science learning journey at **WorldQuant University**.

---

## 📊 Project Overview

The goal of this project is to:
- Analyze housing price patterns in Mexico
- Examine the relationship between property **area (m²)** and **price (USD)**
- Compare average housing prices between different **states**
- Visualize key insights using Python libraries

---

## 🧠 Key Insights
- Larger property areas generally show a positive correlation with higher prices.
- Some states (e.g., Mexico City) show significantly higher prices than others.
- Outliers and negative values were cleaned before performing analysis.

---

## 🛠️ Tools & Libraries Used
- **Python** 🐍
- **Pandas** — for data cleaning and manipulation  
- **Matplotlib** & **Plotly** — for data visualization  
- **NumPy** — for numerical operations  
- **Jupyter Notebook / VS Code** — for development and analysis  

---

## 📁 Dataset
The dataset used is `mexico_real_estate_messy_v*.csv`, containing:
- Property details (area, price, location)
- Regional information (state, city, municipality)

> Data was cleaned and processed to handle missing values, inconsistent formats, and negative prices.

---

## 📈 Visualizations
Key plots include:
- Scatter plot of **Price vs. Area**
- Bar chart comparing **average price per state**
- Boxplots to detect **price distribution and outliers**
