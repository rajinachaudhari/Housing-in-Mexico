## 1. Tabular Data Structures in Python

### Using Pandas
- **Pandas** is a library for data manipulation and analysis.
- You created a DataFrame (table) for employees:

```python
import pandas as pd
employee = pd.DataFrame({
    "name": ["rajina", "sajina", "aajina"],
    "id": [1, 2, 3],
    "salary": [29, 30, 31]
})
print(employee)
```

### Using NumPy
- **NumPy** is used for numerical operations and arrays.
- You created a 2D array for employee data:

```python
import numpy as np

    [1, 2, 3],
    [29, 30, 31]
```

## 2. Lists in Python
- Lists can store multiple data types.
- Example:

```python
house_0_list1 = [18, 4, "$122"]
print(house_0_list1)
```

### Accessing List Items
- Use indices to access items:
  - `list[0]` or `list[-3]`: First item
  - `list[2]` or `list[-1]`: Last item
- Example:

```python
print(house_0_list1[-2])
```

### List Functions
- `type(list)`: Returns the type of the variable.
- `len(list)`: Returns the length of the list.
- `list.append(item)`: Adds an item to the end of the list.

```python
print(type(house_0_list1))
print(len(house_0_list1))
house_0_list1.append("its addition of new item using append")
print(house_0_list1)
```

## 6. Calculating Price per Square Meter for Each House
- You used loops and list operations to calculate and append price per square meter:

```python
for x in house:
    price_per_metre_sq = x[0] / x[1]
    x.append(price_per_metre_sq)
    print(x)
```

- You also used unpacking and index checking to avoid duplicate calculations:

```python
for i in house:
    if len(i) == 3:
        price = i[0]
        area = i[1]
        price_per_metre_sq = price / area
        i.append(price_per_metre_sq)
    print(i)
```
